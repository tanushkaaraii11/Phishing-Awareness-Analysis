# Phishing Awareness Analysis

A comprehensive cybersecurity project focused on analyzing real-world phishing techniques, identifying Indicators of Compromise (IOCs), understanding attacker methodologies, and recommending security controls to defend against phishing attacks.
This project contains ten professionally documented phishing investigations covering a wide range of modern phishing attacks, including credential theft, Business Email Compromise (BEC), QR Code Phishing (Quishing), Vendor Impersonation, Spear Phishing, Whaling, and Multi-Stage Phishing campaigns.

## Project Objectives
The primary objective of this project is to:

- Analyze different phishing attack techniques.
- Identify phishing indicators and Indicators of Compromise (IOCs).
- Understand attacker objectives and social engineering methods.
- Document attack chains and possible business impacts.
- Recommend appropriate incident response procedures.
- Suggest security controls to reduce phishing risks.
- Improve cybersecurity awareness and phishing detection skills.
